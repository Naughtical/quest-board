# ⚔️ ADHD Quest Board

A medieval-themed productivity and task management app built for neurodivergent brains. Turn your to-do list into a quest board — complete quests, earn XP, level up, and keep your streak alive.

![Quest Board Preview](https://naughtical.neocities.org/quest-board.html)

## ✨ Features

- **Quest Board** — Add tasks as quests with difficulty ranks (Common → Legendary), step-by-step breakdowns, deadlines, and rewards
- **Notice Board** — Daily and one-off tasks with XP rewards
- **Calendar** — Monthly view with event tracking and a day planner
- **XP & Levelling** — Earn XP for completing tasks and level up your hero
- **Streak Tracker** — Optional daily streak with grace days for bad days
- **Gold & Shop** — Spend earned gold on themes, perks, and personal rewards
- **Quest Library** — Save reusable quest templates to pull from later
- **Notice Cards** — Daily rotating inspirational/motivational cards (unlockable)
- **Ship's Log / Scratch Pad** — A persistent freeform notes area
- **Multiple Themes** — Medieval (default), Pirate, Forest, Sci-Fi, Neon Nights, Red Alert
- **Drag to reorder** — Quests and notices are drag-and-drop sortable
- **100% local** — All data saved in your browser's localStorage. No account, no server, no tracking.

## 🚀 How to Use

No installation needed. It's a single HTML file.

1. Download `quest-board.html`
2. Open it in any modern browser
3. Start adding quests!

Or visit the live demo: [naughtical.neocities.org/quest-board.html](https://naughtical.neocities.org/quest-board.html)

## 💾 Data & Privacy

All your data is stored locally in your browser via `localStorage`. Nothing is sent anywhere. Clearing your browser data will erase your quests, so use the **Export** button regularly to back up your data as a JSON file.

## 📋 Quest Ranks

| Rank | XP | Intended for |
|---|---|---|
| Common | 10 | Tiny wins — drinking water, replying to a message |
| Uncommon | 20 | Easy but real — tidying a surface, a short walk |
| Rare | 40 | Actual effort — cooking a meal, a phone call |
| Epic | 70 | Hard things — admin, appointments, big social events |
| Legendary | 100 | Boss battles — moving house, job applications, crises |

## 🛠️ Self-Hosting

Drop the HTML file anywhere that serves static files:

- **Neocities** — upload and visit `yoursite.neocities.org/quest-board.html`
- **GitHub Pages** — add to your repo and enable Pages
- **Any web host** — it's one file, no build step needed
- **Locally** — just open the file in your browser
